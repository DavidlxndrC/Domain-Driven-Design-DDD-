# Taller 11 - Domain-Driven Design (Banco de Preguntas Saber PRO)

Dominio en Java 17 puro (sin Spring ni JPA) con pruebas JUnit 5.

- Raíz del agregado: `Pregunta`
- Objetos de valor: `Enunciado`, `Justificacion`, `OpcionRespuesta`
- Excepción de dominio: `ReglaNegocioException`

Ejecutar pruebas: `mvn test`
